# Холодильник

Учебный проект: страница со списком продуктов в холодильнике — таблица, добавление и удаление строк.

Стек: React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:5173`.

## Данные

Таблица не подключена к настоящей базе данных. Вместо этого используется
заглушка `src/services/FridgeItemService.ts` — объект с методами `all/get/add/delete`,
которые работают с обычным массивом в памяти. При перезагрузке страницы
данные сбрасываются к начальным.

## Сервер-заглушка (Express)

В папке `server/` лежит отдельный Express-сервер-заглушка
(`GET/POST/DELETE /api/fridge-items`), который пока не подключён к
фронтенду — сайт с ним не общается. Запускается отдельно:

```bash
npm run server
```

Сервер поднимется на `http://localhost:3001`.
